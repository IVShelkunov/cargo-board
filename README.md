# Logistics CRM (Cargo System)

A professional B2B solution for managing logistics orders. The application is designed with a focus on high performance, strict data typing, and a user-friendly interface (UX).

## 🚀 Technology stack
- **Frontend:** React, TypeScript
- **State Management:** TanStack Query (серверное состояние), Zustand (UI-стейт)
- **Forms & Validation:** React Hook Form, Zod
- **API:** Axios (с интерсепторами), json-server (Mock API)
- **Styling:** Tailwind CSS
- **Routing:** React Router v6

## ✨ Key functions
- **Auth Hydration:** Secure authentication with session persistence
- **Master-Detail View:** Intuitive interface with order preview and management.
- **Wizard Forms:** Multi-step order creation with cross-field validation (`superRefine`).
- **Data Filtering:** Searching server-side data using `debounce`.
- **Responsive UI:** Responsive design for mobile devices.

## 📦 Installation
1. Clone the repository: `git clone ...`
2. Install dependencies: `npm install`
3. Start the mock server: `npm run server`
4. Launch the application: `npm run dev`
